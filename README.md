# تحسين الرؤية (Lensy Optimization)

Помощник для PUBG MOBILE на iPhone: состояние телефона, готовность к игре, профили графики под модель, пинг по регионам, советы.

Каждый push в ветку `gfx` собирает IPA на GitHub Actions.
Скачать: https://github.com/romakul323-debug/fte/releases/download/gfx-build/Lensy-Optimization.ipa — ставить через Sideloadly.
