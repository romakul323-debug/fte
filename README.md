# Волна — мессенджер со звонками

Серверы, текстовые и голосовые каналы, видео, демонстрация экрана. Работает в браузере на ПК, Android и iPhone. На телефоне ставится на главный экран как приложение.

## Запуск на своём ПК

1. Поставь Node.js LTS: https://nodejs.org (кнопка LTS, всё по умолчанию).
2. Запусти `start.bat`. Первый раз он сам скачает зависимости.
3. Открой http://localhost:3000, зарегистрируйся, нажми «+» и создай сервер.

Данные (аккаунты, сообщения) лежат в папке `data/`. Удалишь её — всё обнулится.

## Как позвать друзей и зайти с телефона

Звонки в браузере работают только по **HTTPS**. Самый быстрый способ — бесплатный туннель Cloudflare, без покупки домена и сервера:

1. Один раз установи cloudflared. В PowerShell: `winget install Cloudflare.cloudflared`
2. Пока работает `start.bat`, запусти `tunnel.bat`.
3. В окне появится ссылка вида `https://что-то-там.trycloudflare.com` — её и кидай друзьям.

Ссылка живёт, пока открыты оба окна и включён ПК. При каждом запуске туннеля ссылка новая.

## iPhone

1. Открой ссылку в **Safari**.
2. Нажми «Поделиться» → «На экран Домой».
3. Запускай с иконки «Волна». Микрофон и камеру разрешить при первом звонке.

Ограничения iPhone в веб-версии: нет демонстрации экрана, звонок обрывается, если свернуть приложение надолго.

## Приложения Android и iOS

Папка `app/` — то же приложение, упакованное через Capacitor. Собирает его GitHub Actions (`.github/workflows/build-apps.yml`) при каждом push. Готовые файлы появляются в разделе **Releases** репозитория:

- `Volna.apk` — Android. Скачать на телефон, разрешить установку из неизвестных источников, установить. Новые версии ставятся поверх старой.
- `Volna-unsigned.ipa` — iPhone. Ставится с ПК через **Sideloadly** (sideloadly.io): подключаешь айфон кабелем, перетаскиваешь .ipa, вводишь свой Apple ID. На бесплатном Apple ID приложение нужно переподписывать раз в 7 дней. С платным аккаунтом разработчика можно раздавать через TestFlight.

При первом запуске приложение спросит **адрес сервера** — это https-ссылка из `tunnel.bat` (или адрес твоего VPS). Адрес можно вшить в сборку: в GitHub → Settings → Secrets and variables → Actions → Variables создай `VOLNA_SERVER`.

## Ограничения текущей версии

- В одном голосовом канале до 10 человек. Звонок идёт напрямую между участниками; для больших каналов нужен медиасервер (LiveKit).
- У части пользователей за строгим NAT/мобильным интернетом звонок может не соединиться. Это лечится TURN-сервером (coturn). Его адрес задаётся переменными перед запуском:
  `TURN_URL=turn:твой-сервер:3478`, `TURN_USER=...`, `TURN_PASS=...`
- Нет личных сообщений, картинок и пуш-уведомлений — это следующие шаги.

## Чтобы работало 24/7

Нужен VPS с Linux (самый дешёвый тариф хватит) + домен. Там: `npm install`, `node server.js` под pm2, nginx с HTTPS (Let's Encrypt) и coturn для звонков.

## Структура

```
server.js        — сервер: вход, серверы, каналы, сообщения, сигналинг звонков
db.js            — хранение в data/db.json
public/app.js    — весь клиент: интерфейс + звонки WebRTC
public/style.css — оформление
public/sw.js, manifest.json — установка как приложения (PWA)
```

Порт меняется переменной `PORT` (по умолчанию 3000).
