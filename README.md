# Волна — мессенджер со звонками

Серверы, текстовые и голосовые каналы, видео, демонстрация экрана. Работает в браузере на ПК, Android и iPhone. На телефоне ставится на главный экран как приложение.

## Что умеет

- Серверы с текстовыми и голосовыми каналами, личные сообщения и звонки в личке (с входящим вызовом).
- Ответы, правка (↑ на ПК), реакции (двойной тап — ❤️), картинки (вставка, перетаскивание), упоминания @ник, **разметка**, ||спойлеры||.
- Профиль: аватар и баннер-картинки, отображаемое имя, стиль имени (цвет/градиент/переливы), рамка аватара, описание, местоимения, статус (в сети / не активен / не беспокоить / невидимка) и свой статус с эмодзи.
- Голос: шумодав, который отсекает тапы и щелчки, автоматическая чувствительность, громкость каждого участника, автовосстановление звука после прерываний (игры, сворачивание), запасной путь через сервер.
- Внешний вид: жидкое стекло, обои (или своя картинка), прозрачность и размытие стекла, размер текста.

## Запуск сервера на своём ПК (бесплатно, без VPN)

1. Зарегистрируйся на https://tuna.am (бесплатно) и в личном кабинете скопируй **API-ключ** (`tak_…`) и имя **бесплатного постоянного поддомена**.
2. Скачай проект: https://github.com/romakul323-debug/fte/archive/refs/heads/volna.zip и распакуй.
3. Запусти `start.bat`. При первом запуске он сам скачает Node.js и Tuna и спросит ключ и поддомен.
4. В окне появится «✅ Сервер доступен из интернета: https://….ru.tuna.am». Адрес постоянный — его вшивают в приложения.

Пока окно открыто и ПК включён — всё работает. Данные лежат в папке `data/`.

Голос: если напрямую между участниками соединиться не получилось (мобильный интернет, VPN, роутеры), звук сам переключается на путь через сервер — в окне звонка у такого участника пометка «через сервер».

## iPhone

1. Открой ссылку сервера (из окна `start.bat`) в **Safari**.
2. Нажми «Поделиться» → «На экран Домой».
3. Запускай с иконки «Волна». Микрофон и камеру разрешить при первом звонке.

Ограничения iPhone в веб-версии: нет демонстрации экрана, звонок обрывается, если свернуть приложение надолго.

## Приложения Android и iOS

Папка `app/` — то же приложение, упакованное через Capacitor. Собирает его GitHub Actions (`.github/workflows/build-apps.yml`) при каждом push. Готовые файлы появляются в разделе **Releases** репозитория:

- `Volna.apk` — Android. Скачать на телефон, разрешить установку из неизвестных источников, установить. Новые версии ставятся поверх старой.
- `Volna-unsigned.ipa` — iPhone. Ставится с ПК через **Sideloadly** (sideloadly.io): подключаешь айфон кабелем, перетаскиваешь .ipa, вводишь свой Apple ID. На бесплатном Apple ID приложение нужно переподписывать раз в 7 дней. С платным аккаунтом разработчика можно раздавать через TestFlight.

Приложение само узнаёт текущую ссылку сервера: `start.bat` публикует её через ntfy.sh (канал задан в `volna.config.json`). Если сервер переедет на постоянный адрес (VPS), впиши его в `volna.config.json` → `server`, и он будет вшит в сборку. Вручную адрес можно указать на экране входа («Указать свой сервер»).

## Ограничения текущей версии

- В одном голосовом канале до 10 человек. Звонок идёт напрямую между участниками; для больших каналов нужен медиасервер (LiveKit).
- У части пользователей за строгим NAT/мобильным интернетом звонок может не соединиться. Это лечится TURN-сервером (coturn). Его адрес задаётся переменными перед запуском:
  `TURN_URL=turn:твой-сервер:3478`, `TURN_USER=...`, `TURN_PASS=...`
- Нет личных сообщений, картинок и пуш-уведомлений — это следующие шаги.

## Свой сервер в России (рекомендуется)

Зарубежные хостинги в России часто без VPN не открываются, а для звонков через мобильный интернет нужен сервер-посредник (TURN). Оба вопроса решает один российский VPS (Ubuntu 22.04/24.04, от ~150 ₽/мес):

```
curl -fsSL https://raw.githubusercontent.com/romakul323-debug/fte/volna/deploy/install.sh | bash
```

Скрипт ставит мессенджер, HTTPS (адрес вида `1-2-3-4.sslip.io`), coturn для звонков и автообновление из этой ветки каждые 3 минуты. Данные хранятся на диске сервера (`/var/lib/volna`).

## Бесплатный хостинг 24/7 (Render + Neon)

Чтобы сервер работал без твоего ПК:

1. **База.** Создаётся на Render автоматически (бесплатная, живёт 30 дней). Для постоянной: зарегистрируйся на https://neon.com, создай проект и замени в Render переменную `DATABASE_URL` на строку из Neon.
2. **Сервер (Render).** Открой https://render.com/deploy?repo=https://github.com/romakul323-debug/fte/tree/volna → войди через GitHub → **Deploy Blueprint**.
3. Через пару минут сервер будет по адресу вида `https://volna-xxxx.onrender.com`. Он сам опубликует свой адрес — приложения найдут его без ввода.

**Текущий сервер:** https://volna-r9gy.onrender.com — вшит в приложения (`volna.config.json` → `server`).

Бесплатный Render засыпает после 15 минут тишины; сервер сам себя будит раз в 10 минут, чтобы этого не было (выключается переменной `KEEP_AWAKE=0`). Лимит — 750 часов в месяц, этого хватает на один сервер круглосуточно. Каждый push в ветку `volna` обновляет сервер автоматически.

## Вход через Google и по коду на почту

Кнопки появляются сами, как только на сервере заданы переменные (Render → сервис volna → Environment):

- **Google:** `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` — из Google Cloud Console → APIs & Services → Credentials → OAuth client ID (тип «Web application»). В «Authorized redirect URIs» добавь `https://volna-r9gy.onrender.com/auth/google/callback`.
- **Код на почту:** `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS` (и по желанию `SMTP_FROM`). Для Gmail: `smtp.gmail.com`, `465`, твоя почта и пароль приложения (myaccount.google.com/apppasswords).

## Структура

```
server.js        — сервер: вход, серверы, каналы, сообщения, сигналинг звонков
db.js            — хранение в data/db.json
public/app.js    — весь клиент: интерфейс + звонки WebRTC
public/style.css — оформление
public/sw.js, manifest.json — установка как приложения (PWA)
```

Порт меняется переменной `PORT` (по умолчанию 3000).
